# スケジューラシミュレーション結果可視化ツール

Result_visualizer.py
スケジューラシミュレーションの結果をグラフ化するための可視化ツール

## 機能

- データの可視化（散布図）
- ファイルからのデータ読み込み
- 手動でのデータ入力
- グラフの保存機能

## 使用方法

### 1. ファイルからデータを読み込む場合

1. データファイルを `plot/input_data/` ディレクトリに配置します。

   - ファイル形式: `.txt`
   - データ形式:

     ```
     データセット名

     [[x1 y1]
      [x2 y2]
      [x3 y3]
      ...]
     ```

2. プログラムを実行します：

   ```bash
   python src/utils/result_visualizer.py
   ```

3. メニューから「1」を選択してファイルから読み込みます。

4. 表示されるファイル一覧から、読み込むファイルの番号を選択します。

5. グラフのタイトルを入力します（デフォルト: Results Visualization）。

6. グラフの保存オプションを選択します：
   - 保存する場合（y）:
     - ファイル名を入力するか、Enter を押して自動生成
     - 保存先: `plot/` ディレクトリ
   - 保存しない場合（n）:
     - グラフが表示されます

### 2. 手動でデータを入力する場合

1. プログラムを実行します：

   ```bash
   python src/utils/result_visualizer.py
   ```

2. メニューから「2」を選択して手動入力を開始します。

3. データセット名を入力します。

4. データを入力します：

   - 形式: `[x y]`（例: `[110 39]`）
   - 空行を入力してデータセットを終了

5. 新しいデータセットを入力する場合は、新しいデータセット名を入力します。

   - 終了する場合は「q」を入力

6. グラフのタイトルを入力します（デフォルト: Results Visualization）。

7. グラフの保存オプションを選択します：
   - 保存する場合（y）:
     - ファイル名を入力するか、Enter を押して自動生成（タイムスタンプ付き）
     - 保存先: `plot/` ディレクトリ
   - 保存しない場合（n）:
     - グラフが表示されます

## 注意事項

- グラフを保存した場合、プログラムは自動的に終了します。
- グラフを保存しない場合、グラフが表示され、プログラムは継続します。
- 入力データは必ず `[x y]` の形式で入力してください。
- ファイル名を指定しない場合、自動的にファイル名が生成されます。
